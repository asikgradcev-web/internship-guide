Как составить резюме без опыта?

Структура идеального резюме студента

1. Образование

Укажите ваш вуз, факультет и курс. Обязательно добавьте релевантные предметы:

  • Алгоритмы и структуры данных
  • Базы данных
  • Веб-разработка
  • Объектно-ориентированное программирование
  • Операционные системы

🛠️ 2. Пет-проекты (самое важное!)

Даже если у вас нет коммерческого опыта, учебные проекты — это уже опыт. Сделайте 2–3 проекта и выложите на GitHub:

  • Калькулятор — показывает знание основ языка
  • TODO-лист — работа с DOM и хранением данных
  • Telegram-бот — работа с API
  • Простой сайт — HTML/CSS/JS

Обязательно укажите ссылку на GitHub и живое демо проекта.

💡 3. Навыки

Разделите навыки на категории:

  • Языки: Python, JavaScript, Java, C++, SQL
  • Фреймворки: React, Django, Spring, Flask
  • Инструменты: Git, Docker, Linux, VS Code
  • Базы данных: PostgreSQL, MySQL, MongoDB

⚠️ НЕ пишите «уверенный пользователь ПК» или «коммуникабельность» — это не работает.

🏆 4. Достижения

  • Олимпиады по программированию
  • Хакатоны (даже участие ценится)
  • Волонтерство в IT-проектах
  • Онлайн-курсы: Stepik, Coursera, Яндекс.Практикум
  • Сертификаты и дипломы

✍️ 5. О себе

2–3 предложения о том, кто вы, что хотите делать и почему именно эта компания. Избегайте штампов вроде «стремлюсь к развитию».

Хороший пример: «Студент 3 курса, увлекаюсь веб-разработкой. Сделал 3 пет-проекта на React. Хочу развиваться в frontend-разработке и работать в продуктовой команде».
